# Expense Tracker App 💰

A beginner-friendly expense tracker built with Python and Flask to practice programming, web development, and expense management.

## 📌 About the Project

The Expense Tracker App allows users to record expenses with descriptions and amounts through a simple web interface. This project started as a Python programming exercise and was expanded into a web application using Flask, HTML, CSS, and JavaScript.

It is a learning project focused on applying programming concepts to a practical, real-world problem.

## ✨ Features

- Add expense descriptions and amounts
- Organize expense entries
- Calculate and display expense totals
- Interact with the tracker through a web interface
- Use a separate Python script to practice the original expense-tracking logic
- Basic input validation for a better user experience

## 🛠️ Technologies Used

- **Python** — application logic and calculations
- **Flask** — web application framework
- **HTML** — page structure
- **CSS** — styling and layout
- **JavaScript** — client-side interactions and validation
- **Git and GitHub** — version control and project sharing

## 🚀 How to Run the Project

### Prerequisites

- Python installed on your computer
- pip, Python's package installer

### Installation

1. Clone this repository:

   ```bash
   https://github.com/rimshabukhari004/expense-tracker-python-project.git
   ```

2. Navigate into the project folder:

   ```bash
   cd "Expense Tracker App"
   ```

3. Install Flask:

   ```bash
   python -m pip install flask
   ```

4. Start the application:

   ```bash
   python app.py
   ```

5. Open the local URL displayed in your terminal in your web browser.
